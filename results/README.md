# Results

This directory is used for machine-readable outputs generated by the reproduction scripts in `experiments/`.

Typical outputs include:

- benchmark model comparisons
- Daily / Weekly / Daily+Weekly input comparisons
- Single / Fixed / Static / Adaptive mechanism ablations
- multi-seed Adaptive vs. Static robustness results
- moving-block bootstrap and HAC/DM inference
- router diagnostics

The experiment scripts create the relevant CSV files in this directory when executed.

Precomputed research artifacts from the original development pipeline are not included here; the public repository contains the cleaned final-paper implementation and reproduction workflow.
